# MAI — MAILAB-WORKSPACE

Repositório oficial da MAI: produtos digitais pequenos, rápidos e
rentáveis, criados com apoio de humanos e IAs especializadas.

## Comece por aqui

1. Leia a [MAI Central](./MAPA-WIREFRAME-MVP-MAI.md).
2. Confira o [organizador do Discord](./discord-organizer/README.md).
3. Leia o [norte da integração Grok + GitHub + Discord](./docs/INTEGRACAO-GROK-DISCORD-GITHUB.md).
4. Veja o [protótipo de conversa do Grok](./grok-bridge/README.md).
5. Veja as [fichas dos especialistas](./agentes/README.md).
6. Veja o [transcritor local de vídeo](./video-transcriber/README.md).
7. Veja os [aprendizados para agentes de IA](./docs/APRENDIZADOS-AGENTES-IA.md).
8. Use os [templates de agentes, memória e skills](./docs/templates/).
9. Veja o [próximo passo](./docs/PROXIMO-PASSO.md).
10. Veja as [Issues](https://github.com/mvicxn/MAILAB-WORKSPACE/issues).
11. Para qualquer alteração, crie uma branch e um Pull Request.
12. Veja o [catálogo do lote de treinamentos](./docs/treinamentos/LOTE-04-20.md).

## Fonte oficial

- **GitHub:** código, documentos, Issues, Pull Requests e histórico.
- **Discord:** conversa, alinhamento, alertas e coordenação.
- **MAI Central:** regras gerais, visão, processo e decisões estruturais.

## Regra de segurança

Nunca publique tokens, senhas, chaves, arquivos `.env`, dados pessoais
desnecessários ou documentos confidenciais neste repositório.

## Fluxo mínimo

```text
Issue
→ branch
→ alteração
→ commit
→ Pull Request
→ revisão
→ merge na main
```
